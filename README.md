# 智仓 · 3D 智慧仓库演示

真实 Three.js/WebGL 三维仓库，4 排 × 5 层 × 10 列共 200 库位，40 种商品、292 条初始库存和 292 条初始流水。

包含库存明细、出入库、移库补货任务和预警处理。支持主管给小王派单、切换演示身份领取任务、完成后更新库存与三维状态。

## 数据范围

这是用户明确选择的 GitHub Pages 浏览器本地演示版。库存和任务通过 IndexedDB 事务保存于当前浏览器。刷新后保留，同一浏览器的标签页可读取更新；不同电脑、浏览器和用户之间不共享。演示身份不是账号鉴权。清除网站数据会清除演示操作，顶部提供重置按钮。

原有服务端数据库版仍在原工程中，未被此发布替换。本仓库仅包含仓库演示源码和生成的模拟数据，不含部署凭证或原项目的私有运行信息。

## 本地运行

Node.js 24：`npm ci`、`npm test`、`npm run dev`。发布构建：`npm run build`。GitHub Actions 自动测试、构建并发布 `dist` 到 Pages。页面采用 hash 导航，直接链接和刷新均适用于项目子路径。
